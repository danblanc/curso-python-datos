# Clase 3 — Iteraciones, funciones y manejo de errores

**Duración:** 2 horas
**Modalidad:** Virtual

## Objetivos de aprendizaje

- Usar bucles `for` para recorrer listas, diccionarios y rangos de números.
- Usar bucles `while` y entender el riesgo de un bucle infinito.
- Escribir *list comprehensions* simples.
- Definir funciones propias, con y sin parámetros, con y sin retorno.
- Entender el concepto de *scope* (alcance de variables).
- Anticipar y manejar errores con `try`/`except`, evitando que un programa se caiga por un dato inesperado.

## Contenidos

1. Bucle `for`: recorrer listas, diccionarios, `range()`
2. Bucle `while` y control de bucles infinitos
3. `break` y `continue`
4. List comprehensions
5. Funciones: definición, parámetros, valores por defecto, `return`
6. Scope de variables (local vs. global, idea general)
7. Errores comunes en Python: tipos de excepciones
8. `try` / `except` / `else` / `finally`

## Prerrequisitos

Clases 1 y 2 (entorno funcionando, tipos de datos, estructuras nativas, condicionales).

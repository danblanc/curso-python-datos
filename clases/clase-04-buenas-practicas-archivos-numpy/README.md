# Clase 4 — Buenas prácticas, archivos y NumPy

**Duración:** 2 horas
**Modalidad:** Virtual

## Objetivos de aprendizaje

- Aplicar convenciones básicas de estilo (PEP8) y organizar código en módulos simples.
- Leer y escribir archivos de texto plano y CSV usando Python puro (sin Pandas).
- Usar el bloque `with` para el manejo seguro de archivos.
- Entender qué es un array de NumPy y en qué se diferencia de una lista.
- Realizar operaciones vectorizadas básicas con NumPy.

## Contenidos

1. PEP8: convenciones de estilo en Python
2. Organización de código en módulos (`import` de archivos propios)
3. Lectura y escritura de archivos de texto (`open`, `with`)
4. Lectura y escritura de CSV con el módulo `csv`
5. Introducción a NumPy: por qué existe, qué problema resuelve
6. Arrays de NumPy: creación, indexado
7. Operaciones vectorizadas vs. bucles
8. Funciones estadísticas básicas de NumPy (`mean`, `sum`, `std`, `min`, `max`)

## Prerrequisitos

Clases 1 a 3.

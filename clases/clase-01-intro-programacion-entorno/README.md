# Clase 1 — Introducción a la programación y configuración del entorno

**Duración:** 2 horas
**Modalidad:** Virtual

## Objetivos de aprendizaje

Al finalizar esta clase, se espera que el alumno pueda:

- Explicar con sus palabras qué es programar y qué rol cumple Python como lenguaje.
- Diferenciar un lenguaje interpretado de uno compilado, a nivel conceptual.
- Ejecutar comandos básicos en la terminal (navegación de carpetas, ejecución de un script).
- Ejecutar un script de Python desde la terminal y desde VS Code.
- Diferenciar cuándo conviene usar un script (`.py`) y cuándo un notebook (`.ipynb`).
- Explicar qué es un paquete/librería y cómo se instala con `pip`.
- Explicar qué es un entorno virtual y por qué es una buena práctica usarlo.
- Crear y activar un entorno virtual, e instalar un paquete dentro de él.

## Contenidos

1. ¿Qué es programar? Instrucciones, algoritmos, lenguajes
2. ¿Qué es Python? Por qué es popular para datos
3. Lenguajes interpretados vs. compilados (concepto general)
4. La terminal: navegación básica (`cd`, `ls`/`dir`, `pwd`)
5. Ejecutar un script de Python desde la terminal
6. Herramientas de trabajo: VS Code vs. Jupyter Notebook — cuándo usar cada uno
7. Paquetes y librerías: qué son, `pip install`
8. Entornos virtuales: qué son y por qué importan
9. Creación y activación de un entorno virtual

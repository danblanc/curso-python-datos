# Clase 2 — Tipos, estructuras y condicionales

**Duración:** 2 horas
**Modalidad:** Virtual

## Objetivos de aprendizaje

- Declarar y usar variables de distintos tipos (`int`, `float`, `str`, `bool`, `None`).
- Reconocer cuándo Python convierte tipos implícitamente y cuándo hay que hacerlo explícitamente.
- Usar las cuatro estructuras nativas principales: listas, tuplas, diccionarios y sets, y elegir cuál corresponde según el caso.
- Aplicar operadores aritméticos, de comparación y lógicos.
- Escribir estructuras condicionales (`if`/`elif`/`else`) para tomar decisiones en el código.

## Contenidos

1. Variables: asignación, nombres válidos, convenciones
2. Tipos de datos básicos: `int`, `float`, `str`, `bool`, `None`
3. Conversión de tipos (`int()`, `str()`, `float()`)
4. Listas: creación, indexado, métodos comunes
5. Tuplas: qué las diferencia de las listas (inmutabilidad)
6. Diccionarios: pares clave-valor
7. Sets: colecciones sin duplicados
8. Operadores aritméticos, de comparación y lógicos
9. Condicionales: `if`, `elif`, `else`

## Prerrequisitos

Haber completado la Clase 1 (entorno funcionando, saber ejecutar un script).
